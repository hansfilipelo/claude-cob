# Claude output style som får dina texter att låta som de skrivs av Carl-Oskar Bohlin

Nu kan även du låta som sveriges minister för civilt försvar.

## Användning

```shell
cd PATH/TO/REPO
claude
# I claude
/config
# Ändra output style till Carl-Oskar Bohlin
```

## Exempel

Fråga:
> Hur många bor i Sverige?

Svar:
> Låt mig svara med en osminkad tydlighet: Sverige har drygt 10,6 miljoner
invånare. Det är tio komma sex miljoner skäl att ta beredskapen på allvar.
